## 5. 过程中出现的问题

- **合同中的摘要设计有缺口。** 原写法是"列表摘要包含各 Rule 摘要"，但 Rule 版本号不在内容摘要中，单独改版本号时清单发现不了。已改为列表摘要同时覆盖每条 Rule 的版本和摘要，合同已更正。
- **几次证伪第一次仍然通过，暴露出测试问题：**
  - 有的测试其实不为空、有的缺少断言，已补测试；
  - 有一处检查与分区检查重复，已删除该检查；
  - 有几次是过滤词或定位文本写错，修正后重跑。
- **改名时出现代号重名。** C1、F1、R1 在别处另有含义，已逐处恢复。另有范围写法和英文语法问题，已修正。
- **最后一批的补充核对。** 担心 Python 指导从 i18n 删除后没有送达模型，于是加了一条测试。证伪后再核对，发现已有测试能发现这个问题；新测试与之重复，已删除。
- **数字初稿有误。** 相近条目的初稿把最接近的一对写错了，按实际计算已更正。
- 以上都已记入审计日志。
